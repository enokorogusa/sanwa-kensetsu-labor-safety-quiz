# 建設現場の労働災害クイズ（インターンシップ用）

三和建設のインターンシップで使う、建設・土木現場の労働災害を学ぶ4択クイズアプリです。
サーバーやアカウント登録は不要で、`index.html` をブラウザで開くだけで使えます。

## 使い方

1. このフォルダごとインターン生のPC・タブレットに渡す（USB、社内共有フォルダなど）。
2. `index.html` をダブルクリックしてブラウザで開く。
3. 「死亡者数編」または「傷病者数編」を選んでクイズを開始する。
4. 4択から1つ選ぶと、その場で正解・不正解と簡単な解説が表示される。

インターネット接続は不要です。サーバーを立てる必要もありません。

## 構成

```
index.html                          … トップ画面（モード選択・ミチハロくん紹介）
quiz.html                           … クイズ画面
css/style.css                       … 共通スタイル
js/app.js                           … クイズ進行ロジック
data/questions_death.js             … 死亡者数編 50問
data/questions_injury.js            … 傷病者数編 50問
data/category_images.js             … 事故の型（カテゴリ）ごとのイラスト対応表
assets/michiharo_placeholder.svg    … 仮マスコット（後述の通り差し替え可能）
assets/illustrations/               … 事故の型ごとのオリジナルイラスト（14種類）
```

## 出題の考え方

厚生労働省が公表している建設業の労働災害統計をもとに、実際に発生件数の多い事故の型を優先して出題しています。

- **死亡者数編**：「建設業における労働災害の発生状況（令和6年確定値）」の事故の型別死亡者数ランキング（墜落・転落77人、崩壊・倒壊30人、はさまれ・巻き込まれ25人…）に基づき、件数の多い型を厚めに配分。
- **傷病者数編**：厚生労働省の休業4日以上の死傷災害統計（令和5年確定値、事故の型別）に基づき配分。死亡者数編とはランキングの順位が一部異なります（例：死亡では上位に入らない「転倒」「切れ・こすれ」が傷病者数では上位に来るなど）。

各問題は、厚生労働省「職場のあんぜんサイト」等が公表している建設業の典型的な災害パターン・原因・対策の知見を参考に、教材用に一般化・創作したものです。実在の個別事例・特定の企業・個人を示すものではありません。

## ミチハロくん（仮キャラクター）について

`assets/michiharo_placeholder.svg` は、三和建設の正式なマスコット「ミチハロくん」の**仮の代役イラスト**です。著作権的に無関係な、ヘルメットをかぶった簡易な丸キャラクターとして作成しています。

**正式な画像に差し替える手順：**

1. 差し替えたい画像ファイル（PNG推奨）を用意する。
2. ファイル名を `michiharo_placeholder.svg` と同じ場所に `michiharo.png` のように保存する。
3. `index.html` と `quiz.html` 内の以下の記述を、新しいファイル名に書き換える（2箇所ずつ、テキストエディタで開いて「michiharo_placeholder.svg」を検索・置換するだけでOK）。
   ```html
   <img src="assets/michiharo_placeholder.svg" alt="ミチハロくん（仮キャラクター）">
   ```
   ↓
   ```html
   <img src="assets/michiharo.png" alt="ミチハロくん">
   ```

エンジニアでなくても、テキストエディタでの文字列置換だけで対応できます。難しければエンジニアに一言依頼してください。

## 問題文のイラストについて

各問題の上には、事故の型（墜落・転落、はさまれ・巻き込まれ、など14種類）ごとのイラストを表示しています。

厚生労働省「職場のあんぜんサイト」に掲載されているイラストは、サイトのフッターに「All Rights Reserved」とだけ記載されており、自由な転載を認める規約が見当たらなかったため、**著作権上のリスクを避け、厚労省の絵とは全く別のオリジナルの簡易イラストを新規作成して使用しています。**

イラストは1問ごとではなく「事故の型」ごとに1枚を使い回しており、`data/category_images.js` にカテゴリ名と画像ファイルの対応表がまとまっています。イラストを差し替えたい場合は、`assets/illustrations/` フォルダ内の該当ファイルを同じファイル名で上書きするか、`category_images.js` 内のパスを書き換えるだけでOKです（各問題データを直接編集する必要はありません）。
